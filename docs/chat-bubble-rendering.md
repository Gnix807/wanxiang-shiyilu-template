# 聊天气泡的整体轮廓

2026-10-16。本轮替代此前“独立 SVG 尖角覆盖在矩形气泡上”的实现。

## 问题与复现

旧尖角由黑色外轮廓与底色填充两层闭合路径组成，并伸入气泡内部。两层覆盖边界在小数像素上的抗锯齿叠画会留下淡灰色矩形痕迹，单纯调整偏移无法消除这种边界。

独立对照页在 DPR 1.25、半像素位置复现了气泡内部灰线：左侧补片附近有 28 个像素偏离应有的纯白色，最大通道差 57；新轮廓同一区域为 0。这里记录的是本地复现，不把它写成 Via 真机调试结论。

## 绘制方案

- 每种配色使用一条完整 SVG 路径，同时定义底色、2px 边框、4px 外圆角和尖角。没有伸入气泡的独立补片，也没有需要对齐的两个图形端点。
- 通过 CSS `border-image` 分区伸缩：正常文字气泡中的边角与尖角保持尺寸，平直部分随文本宽高伸缩。SVG 具有固定的 100×64 自然尺寸；切分线避开斜边和圆角。极矮的空气泡由浏览器按规范缩小边图，不改动排版盒尺寸。
- 保留原有内边距、字体、行高、头像位置、明暗配色、微信/QQ 变体和整体阴影。兼容阅读继续关闭阴影，保持原有阅读设置。
- 不增加运行时 JavaScript、尺寸观察器、绘图循环或外部图片请求。SVG 编码在共享 CSS 中，组件 Props、正文 slot 和可见文字保留。
- 原生边框和底色始终存在。边框图不可显示或浏览器不支持时，退回完整圆角矩形；这时没有装饰尖角，正文与布局继续可用。

实现位于 `src/styles/editorial/chat-bubble.css`，由 `Dialogue.astro` 引入；独立 SVG 尖角和兼容样式中的补片规则已移除。

## 验证

`node scripts/check-chat-rendering.mjs` 直接使用实际共享样式：

- Chrome 与 Edge 各 240 组，共 480 组像素回归。覆盖左右/微信/QQ、明暗、DPR 1 / 1.25 / 2 / 2.625 / 3、1 / 1.25 / 2 / 4 倍页面缩放及半像素位置，补片区域没有检出灰线。
- 无边框图与 SVG 解码失败两种情况下，原生降级截图完全一致，容器尺寸不变；仍有 2px 实线边框。
- 主站真实文章检查长昵称、长链接、头像、320 / 390 / 768 / 1440px，以及系统与网站的四种明暗组合；强制自动深色前后截图一致。
- 两仓库的八类兼容阅读场景与原有 1440px / 390px 连续导航通过。主站完整构建 1334 页，模板 142 页，原有构建提示保留。
- 模板保留自身配置、示例与素材。模板默认示例没有聊天文章；其像素检查直接渲染共享样式，实际文章交互验证在主站完成。

复用已有 `PLAYWRIGHT_MODULE`，设置 `BROWSER_CHANNEL=msedge` 可使用本机 Edge，`CHAT_ARTIFACT_DIR` 可保存截图和汇总。没有安装新浏览器或新依赖。

截图与日志位于主站隔离工作区 `scratch/loading-webview/bubble-frame/`，模板记录在 `scratch/push-validation/bubble-frame-*`。尚未连接安卓 17 / Via 真机，因此不承诺所有浏览器或强制改色实现绝对零差异。
