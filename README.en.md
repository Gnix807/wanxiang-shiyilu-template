# Wanxiang Shiyilu — Astro Blog Template

A paper-inspired Astro blog with Markdown/MDX, Editorial components, local fonts, search, archives, categories, tags, short posts and RSS/Atom feeds.

Use **Node.js 24** and **pnpm 11.2.2**. Install with `pnpm install --frozen-lockfile`, develop with `pnpm dev`, and build with `pnpm build`. Output: `dist/`.

Use GitHub's **Use this template** button to create your own repository. Edit `src/config/site.ts`, `src/config/about.md`, the sample posts and avatar. Set `PUBLIC_SITE_URL` to your final HTTPS URL. Personal accounts, comments and analytics are disabled by default.

For Cloudflare Pages use the Astro preset, build command `pnpm build`, output directory `dist`, Node.js 24 and pnpm 11.2.2. The included workflow only checks the build; it does not deploy to a server.
